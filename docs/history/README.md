# Change History

This directory contains dated summaries of changes, improvements, and major updates to the codebase.

## Purpose

- Track significant changes over time
- Provide context for future developers and AI agents
- Document decisions and their rationale
- Maintain a searchable history of improvements

## Naming Convention

All files follow the format: `YYYY-MM-DD-description.md`

Examples:
- `2025-12-12-improvements.md`
- `2025-12-12-caching-feature.md`
- `2025-12-12-security-updates.md`

## What Goes Here

Create a new dated file for:
- Major feature additions
- Significant refactoring or code improvements
- Architecture changes
- Performance optimizations
- Security enhancements
- Bug fixes with complex changes

## What Doesn't Go Here

- Minor typo fixes
- Simple dependency updates
- Small one-line changes
- Routine maintenance tasks

For these, the git commit message is sufficient.

## Usage by AI Agents

AI coding assistants should automatically create summary files in this directory when completing significant work sessions. See [CLAUDE.md](../../CLAUDE.md) for detailed guidelines.
